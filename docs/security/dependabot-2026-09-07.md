# Dependabot review — 7 September 2026

Reviewed against the main branch. Dismissals are specific to the current dependency usage and must be reconsidered if the described input paths change.

- [Alert #90](https://github.com/viplatform/mui-table-react/security/dependabot/90) — `browserslist` ([GHSA-73wf-gq98-2v4g](https://github.com/advisories/GHSA-73wf-gq98-2v4g)): **upgrade**. Update to the patched release and verify dependency behavior.

- [Alert #88](https://github.com/viplatform/mui-table-react/security/dependabot/88) — `fast-uri` ([GHSA-jqff-g426-hqxp](https://github.com/advisories/GHSA-jqff-g426-hqxp)): **dismiss**. The locked fast-uri dependency is used by Ajv for JSON Schema URI/reference handling. This repository does not import fast-uri, accept untrusted schemas, or use Ajv URI normalization to authorize redirects or outbound destinations. The advisory requires attacker-controlled URLs reaching normalize/resolve before a host/origin/SSRF policy decision; that path is absent. Reassess if remote/untrusted schemas or URL-policy uses are introduced.

- [Alert #84](https://github.com/viplatform/mui-table-react/security/dependabot/84) — `@humanfs/node` ([GHSA-p498-v437-472g](https://github.com/advisories/GHSA-p498-v437-472g)): **dismiss**. @humanfs/node is pulled in by ESLint. ESLint uses hfs.isDirectory and hfs.walk for lint file discovery; its installed lib code has no hfs.copy/copyAll calls, and repository code does not import humanfs. The advisory requires copying attacker-controlled paths/symlinks through those APIs, which this project does not do.

- [Alert #83](https://github.com/viplatform/mui-table-react/security/dependabot/83) — `postcss-selector-parser` ([GHSA-w9m9-85wc-3x92](https://github.com/advisories/GHSA-w9m9-85wc-3x92)): **dismiss**. This dependency processes repository-owned CSS/selectors through build/lint tooling (PostCSS, Tailwind, Stylelint or CSS minification). Application code does not import the parser or compile user-supplied CSS/selectors on a server. The advisory requires attacker-controlled selector AST serialization; runtime inputs cannot reach that build-time path.
